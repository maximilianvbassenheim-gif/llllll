# 💡 Ideen-Speicher — Die 300→3-Methode

*Du wolltest: „aus 300 Vorschlägen immer die 3 besten". So geht das System:*

## So funktioniert's (10 Min pro Woche)

1. **Sammeln (laufend):** JEDE Idee kommt hier rein. Keine Bewertung beim Sammeln!
   Handy-Notiz unterwegs → einmal pro Woche hierher übertragen.
2. **Bewerten (freitags):** Jede neue Idee bekommt 1–5 Punkte in 3 Spalten:
   - **H** = Hook-Kraft (stoppt es den Daumen in 1,5 Sek?)
   - **M** = Machbarkeit (kannst du es MORGEN drehen?)
   - **G** = Geld-Nähe (führt es zu Song-Anfragen?)
3. **Top 3 ziehen:** Die 3 höchsten Summen = deine Reels für nächste Woche. Rest bleibt liegen — nichts wird gelöscht.

> Claude-Tipp: Du kannst mir jederzeit deine Rohliste geben („bewerte meine Ideen")
> — ich sortiere sie dir nach diesem Schema vor.
