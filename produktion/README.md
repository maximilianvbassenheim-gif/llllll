# 📦 PRODUKTION — Dein Produktionsordner

Diese Struktur kannst du 1:1 auf deine lokale Platte spiegeln
(z. B. `E:\PRODUKTION`). Gleiche Ordnernamen, gleiche Logik —
hier im Repo liegt die „Quelle der Wahrheit", lokal liegen deine
großen Dateien (Videos, Audio-Projekte, Rohmaterial).

```
PRODUKTION/
├── 00-START-HIER.md        ← 🔦 DIE FACKEL: lies das zuerst, immer wieder
├── 01-MARKE/               ← Wer ist Shakker Kids? (Figuren, Farben, Ton)
├── 02-CONTENT/             ← Reel-Pläne, Ideen-Speicher (300 → Top 3)
├── 03-VERKAUF/             ← Alle Geld-Routen + Einrichtungsanleitungen
├── 04-SETUP/               ← Instagram & Co. Schritt für Schritt
└── 05-ROUTINE/             ← Deine Tages-/Wochenroutine (30–60 Min/Tag)
```

**Lokal ergänzt du (nur auf deiner Platte, nicht ins Repo):**

```
E:\PRODUKTION\
├── ... (alles von oben)
├── 06-ROHMATERIAL\          ← Video-Clips, Fotos, Sprachaufnahmen
├── 07-AUDIO\                ← Song-Projekte, fertige MP3/WAV je Kunde
└── 08-FERTIG\               ← geschnittene Reels, bereit zum Posten
```

> Regel: **Nichts fliegt lose rum.** Jede Datei hat genau einen Ordner.
> Kundenprojekte in `07-AUDIO` immer als `JJJJ-MM-TT_Kindname_Anlass`.
